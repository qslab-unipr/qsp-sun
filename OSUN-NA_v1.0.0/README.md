# Implementation of the OSUN Algorithm without Ancillary Qubits

## Description

This repository contains a modified (no-ancillae) implementation of the **OSUN quantum state preparation algorithm** [1], derived from the optimized version of the algorithm proposed by Sun et al. [2].

The original OSUN implementation [1] considers an ancillary register within the range defined by the theoretical construction of the historical algorithm [2], namely $m=2n$. The purpose of this project is to investigate an alternative implementation in which the QSP procedure is executed **without ancillary qubits**, reducing the total number of qubits required by the quantum circuit.

The implementation has been developed in Python using the **PennyLane** library for quantum circuit construction and simulation. The structure of the original project [1] has been preserved as much as possible in order to allow a direct comparison between the reference implementation and the modified version.

In addition to the modules inherited from the original OSUN project, the repository includes dedicated scripts for validating the correctness of the modified QSP procedure and for benchmarking its scalability.

The main Python modules are described below:

- *main_opt.py* is the main script used to execute and test the modified OSUN quantum state preparation algorithm.
- *utils_mod.py* contains utility functions for vector manipulation, parameter computation, normalization, result formatting, and other classical preprocessing operations required by the algorithm.
- *circuit_classes.py* contains the classes and circuit-building routines used to construct and simulate the quantum state preparation circuit. In this version, the circuit construction has been adapted to avoid the use of the ancillary register required by the original OSUN implementation.
- *lambda_final.py* computes and analyzes the parameters associated with the final $\Lambda$-type constructor, which is responsible for reproducing the complex phases of the target quantum state.
- *quantum_state_preparation_mod.py* contains the routines used to initialize and execute the complete quantum state preparation procedure. The module has been modified to support the ancillary-free implementation while preserving the logical structure of the original OSUN algorithm.
- *validation_qsp.py* provides numerical validation tests for the modified quantum state preparation procedure. It compares the state generated by the circuit with the desired target state and can be used to verify the correctness of the implementation for different numbers of qubits and different classes of input states.
- *benchmark_scaling.py* evaluates the scalability of the ancillae-free implementation. It is used to collect quantitative information such as circuit size, number of gates, circuit depth, execution time, and other relevant metrics as the number of qubits increases.

The main objective of this implementation is therefore to study the trade-off between **qubit requirements and circuit complexity** when the ancillary register of the original OSUN construction is removed.

[1] Belli, Giacomo, and Michele Amoretti. *Algebraic reduction to improve an optimally bounded quantum state preparation algorithm*, arXiv:2602.06535 (2026).

[2] Sun, Xiaoming, et al. *Asymptotically Optimal Circuit Depth for Quantum State Preparation and General Unitary Synthesis*, arXiv:2108.06150 (2021).

## Requirements

The project is implemented in Python and uses **PennyLane** for quantum circuit construction and simulation.

The main dependencies are:

- Python 3.10 or later;
- PennyLane 0.42.3;
- NumPy;
- Matplotlib.

Standard Python modules such as *math*, *operator*, and other utilities are also used by the implementation.

The exact package versions used for the numerical experiments should be installed according to the environment in which the benchmarks are reproduced.

## Main Functions & Methods

The project preserves the main parameter-computation and circuit-construction workflow of the original OSUN implementation, while modifying the state-preparation stage in order to remove the ancillary register.

### *qspParameters_mod(unit_vector : np.ndarray, n : int)*

Takes the normalized vector corresponding to the desired quantum state and the number of qubits of the input register. It computes the parameters required by the OSUN construction, including the $\alpha$ phase-shift parameters and the quantities associated with the $\Lambda$-type matrices used by the state-preparation procedure.

### Quantum state preparation circuit

The QSP routines contained in *quantum_state_preparation_mod.py* and *circuit_classes.py* construct the modified OSUN circuit using only the qubits required to represent the target state. Compared with the original implementation, the additional ancillary register is removed from the circuit construction. The resulting implementation therefore prepares an $n$-qubit target state using an $n$-qubit quantum register.

### Validation

The script *validation_qsp.py* can be used to verify the correctness of the modified implementation. For a target state $|\psi_{\mathrm{target}}\rangle$, the state produced by the quantum circuit, $|\psi_{\mathrm{QSP}}\rangle$, is numerically compared with the expected result. The validation procedure can be applied to different types of quantum states, including real and complex states, and to different register sizes.

### Scalability Benchmark

The script *benchmark_scaling.py* is used to evaluate how the modified implementation behaves when the number of qubits increases. Depending on the selected experiment, the benchmark can collect quantities such as:

- number of qubits;
- number of quantum gates;
- circuit depth;
- execution or construction time;
- state-preparation accuracy;
- fidelity or numerical error with respect to the target state.

These measurements allow a direct comparison between the reduction in qubit requirements and the additional circuit resources introduced by the ancillary-free implementation.

## Usage

The simplest way to test the implementation is to execute:

```bash
python main_opt.py
```

and follow the instructions displayed in the terminal. As in the original OSUN implementation, the program can be used to prepare different classes of quantum states, including real and complex states. The input vector representing the desired state must have dimension $2^n$ for an $n$-qubit quantum state and must be normalized according to the Euclidean $l_2$ norm. A specific normalized state vector can also be provided directly to the program.

## Validation

To run the numerical validation of the ancillae-free quantum state preparation procedure, execute:

```bash
python validation_qsp.py
```

The validation script verifies that the state generated by the modified circuit reproduces the desired target state within the expected numerical tolerance. This script is particularly useful after changes to the circuit implementation, since it provides an independent check that the removal of the ancillary register does not alter the final prepared quantum state.

## Benchmarking

The scalability experiments can be executed using:

```bash
python benchmark_scaling.py
```

The script evaluates the behavior of the implementation for increasing numbers of qubits and produces the data required to study the resource cost of the ancillae-free construction. The generated results can be used to compare the modified implementation with the original OSUN algorithm in terms of:

- qubit count;
- circuit depth;
- gate count;
- execution time;
- state-preparation accuracy.

## Differences from the Original OSUN Implementation

The main difference between this repository and the original **OSUN** implementation is the elimination of the ancillary quantum register.

In the original construction, additional qubits are introduced to obtain the optimized circuit-depth properties of the OSUN algorithm. In this implementation, the QSP circuit is reformulated so that only the $n$ qubits associated with the target quantum state are required. Consequently, the modified implementation reduces the **qubit count**, at the cost of a different circuit decomposition and potentially different values of circuit depth and gate complexity.

The classical parameter-computation logic and the general organization of the original OSUN project have been preserved whenever possible, making the two implementations directly comparable.

The additional *validation_qsp.py* and *benchmark_scaling.py* modules have been introduced specifically to verify the equivalence of the prepared quantum states and to quantify the resource trade-offs introduced by the ancillae-free implementation.
